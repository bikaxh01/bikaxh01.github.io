# Todo App

A simple todo list built with Next.js (App Router), TypeScript and Tailwind CSS.
Todos are persisted in the browser's `localStorage`, so no backend is required.

## Features

- Add, toggle and delete todos
- Filter by all / active / completed
- Clear completed todos
- State persists across page reloads via `localStorage`

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Other commands

```bash
npm run lint   # ESLint
npm run build  # production build
npm start      # serve the production build
```
